# <img src="docs/readme-svg/sun.svg" width="24" height="24" alt="" style="vertical-align:middle;display:inline-block;margin:0 4px 3px 0;pointer-events:none;"> SunTrack Changelog

<details>
<summary> <img src="docs/readme-svg/flask.svg" width="20" height="20" alt="" style="vertical-align:middle;display:inline-block;margin:0 4px 2px 0;pointer-events:none;"> Version 1.0.0</summary>

### <img src="docs/readme-svg/sparkles.svg" width="18" height="18" alt="" style="vertical-align:middle;display:inline-block;margin:0 4px 2px 0;pointer-events:none;"> Core Features
- Sunrise time calculation based on city location
- Automatic wake-up time calculation (55 minutes before sunrise)
- Automatic departure time calculation (30 minutes before sunrise)
- Live countdown timer to wake-up time
- City selection via GPS or city name search
- Reverse timeline display of morning routine steps
- Current temperature display with hot weather warning (above 26°C)
- Morning routine checklist (hydration, stretching, breathing, essentials check)
- Manual calculator for custom sunrise time input
- Mathematical formula guide page with real-world example
- Automatic saving of location and settings to device storage
- Offline mode with cached data support

### <img src="docs/readme-svg/globe.svg" width="18" height="18" alt="" style="vertical-align:middle;display:inline-block;margin:0 4px 2px 0;pointer-events:none;"> Multi-Language & Multi-Format Support
- Bilingual: Persian (Farsi) and English
- Full RTL support for Persian language
- Jalali (Persian) and Gregorian calendar support
- Three theme modes: Light, Dark, and Auto (system-synced)

### <img src="docs/readme-svg/palette.svg" width="18" height="18" alt="" style="vertical-align:middle;display:inline-block;margin:0 4px 2px 0;pointer-events:none;"> Design & User Interface
- Responsive design for mobile and tablet devices
- Main orange color `#FF7631`
- Warm cream background `#fef8ee`
- Vazirmatn font for Persian text
- Inter font for English text
- Font Awesome 7 icons
- Smooth animations for interactions
- Bottom navigation bar with Home and More sections

### <img src="docs/readme-svg/smartphone.svg" width="18" height="18" alt="" style="vertical-align:middle;display:inline-block;margin:0 4px 2px 0;pointer-events:none;"> Android WebView Compatibility
- Automatic Navigation mode detection (Button/Gesture)
- Auto-adjustment of spacing for Android system bar
- Safe Area support for notch devices
- Full compatibility with system dark mode
